# React Projects Collection

A collection of React applications showcasing modern web development practices, animations, and responsive design.

## 📁 Projects

### 1. My-Portfolio
A modern, responsive portfolio website built with React and Vite, featuring smooth animations, custom cursor effects, and an elegant intro animation.

🌐 **Live Demo**: [https://vikash-portfolio0.netlify.app/](https://vikash-portfolio0.netlify.app/)

**Features:**
- Intro Animation with custom cursor effects
- Smooth animations powered by Framer Motion
- Fully responsive design with Tailwind CSS
- Contact form with EmailJS integration
- Multiple sections: Home, About, Skills, Projects, Contact

**Tech Stack:**
- React 19.2.0
- Vite 7.2.4
- Tailwind CSS 4.1.17
- Framer Motion 12.23.25
- EmailJS 4.4.1

[View Project →](./My-Portfolio)

## 🚀 Getting Started

Each project has its own setup instructions. Navigate to the project folder and follow the README.md inside.

### General Setup:
```bash
# Clone the repository
git clone https://github.com/VikashRaj-cmd/React-Project.git
cd React-Project

# Navigate to a specific project
cd My-Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🛠️ Common Technologies

- **React** - UI library
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework

- **React Icons** - Icon library
